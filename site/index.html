stow

Automatically offload files you haven’t used from your Mac to your own S3, and restore them on demand.

Turn on stow schedule and Stow checks once a day for large, stale files and offloads them — uploading to S3 and freeing the disk space. Smart, conservative defaults: only files ≥ 10 MB, untouched ≥ 90 days (by Spotlight’s last-opened date), in ~/Downloads, ~/Desktop, and ~/Movies. Nothing is touched until it clears every check, and stow restore always brings a file back byte-for-byte.

Offloaded files become small placeholders until you run stow restore (there’s no automatic restore-on-open yet). Run stow scan anytime to preview exactly what would be offloaded — nothing moves on a dry run.

Install

brew tap viraatdas/tap
brew install stow

Use

# one-time: auto-provisions an S3 bucket in your AWS account
stow init

# preview what auto-offload would pick (dry run, no changes)
stow scan

# turn on automatic daily offloading
stow schedule

# bring any file back, byte-for-byte identical
stow restore ~/Movies/big-render.mov

Tune

# adjust the smart defaults
stow config set-size 20        # only files ≥ 20 MB
stow config set-age 30         # untouched ≥ 30 days
stow config add-root ~/Library/Caches

stow config                    # show policy + schedule
stow offload ~/big.zip         # or offload one file by hand

Files are stored in an S3 bucket in your own AWS account, using your existing credentials. Content is hashed and de-duplicated; restores are verified byte-for-byte. Stop automatic offloading anytime with stow unschedule. Apple Silicon, macOS 14+.
